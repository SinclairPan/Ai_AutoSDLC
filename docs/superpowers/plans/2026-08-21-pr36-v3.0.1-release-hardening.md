# PR #36 v3.0.1 Release Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在保持 12 条新用户路线和 v3.0.0 核心运行时兼容的前提下，精确收紧 Linux 在线零 Python 自动安装边界，并让 Windows package-manager bootstrap E2E 真正隔离宿主 Python。

**Architecture:** Linux 先沿用现有 `pick_python` 兼容路径，只在缺少 Python 3.11+ 时执行 Debian 12 AMD64 glibc 的确定性认证；其他 `AMD64/x86_64 + glibc` 无 Python 主机在副作用前 fail-closed 并引导使用既有 bundled-runtime 离线包，非 AMD64 或非 glibc 主机 fail-closed 且明确 v3.0.1 没有兼容资产。Windows 不再修改产品安装器，只收紧测试 harness 的 Machine/User/Process PATH 和解析断言，证明 winget/choco 是唯一 Python 状态转换来源。

**Tech Stack:** Bash、PowerShell、Python/pytest、GitHub Actions YAML、现有 user-guide validator、Ruff、Hatch build。
