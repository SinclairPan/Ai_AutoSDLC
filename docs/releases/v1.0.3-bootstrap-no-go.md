The second failure was caused by a producer/consumer text-boundary defect. The workflow wrote `assets-to-upload.txt` with `"\n".join(upload)` and no final LF, while its POSIX consumer used a plain `while IFS= read -r asset_name`. Bash assigned the final record but returned failure at EOF, so the loop body skipped that record. The omitted record was:

`ai-sdlc-offline-1.0.3-windows-amd64.zip.sha256`

The Proof input/live Draft exact-set check then failed closed with `live Draft asset set differs`.
